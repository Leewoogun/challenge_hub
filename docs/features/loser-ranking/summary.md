# 개돼지 랭킹 (loser-ranking) — Summary

- **feature-id**: loser-ranking
- **완료일**: 2026-08-26
- **상태**: **completed** (서버 실서버 실측 + 양 플랫폼 테스트. 디바이스 실기 확인은 미해결 등재)

## 구현 개요

2026-08-06 기획 축 반전(명예의 전당 → **패자 랭킹**)의 구현 — *"패배의 왕좌, 많이 진 놈이 대장."*
랭킹 탭이 실화면이 되면서 **4탭 placeholder 가 0이 됐다.** 나+친구를 총 패배 기준으로 줄 세워
Top3 포디움(1위 개돼지왕 🐷)과 "수치의 명단"으로 그린다. challenge-result 가 채우기 시작한
`user_stats`(연패 컬럼 포함)의 첫 소비자다. **데이터·디자인이 모두 준비된 상태에서 시작한 첫
feature** 라 계약 협의가 유난히 빨랐고, 대신 이번 feature 의 특징은 **팀의 자기 교정 3건**이었다
(결정 사항 7·8 참조).

## 테스트 결과

- **백엔드: 417/417 passed** (466 중 통합 49 skip. 신규 29, 회귀 0) + **실서버 실측 2회** —
  정렬 4키의 실데이터 재현(패율 100% 가 rank 2·4, 80% 가 rank 1), 친구 범위 격리 3계정,
  `LEFT JOIN`+`COALESCE 0` 폴백(계정을 심어 검증 — native query 라 슬라이스가 원리적으로 못 덮는 유일 축)
- **모바일: Android 460/460 + iOS 148/148** (신규 44, 회귀 0) — 계약 9필드 필드별 대조 차이 0,
  재계산 금지 grep 준수, 실서버 원문 픽스처 6건(재정렬하면 반드시 깨지는 단언 포함)

## 결정 사항

1. **정렬**: `losses → currentLossStreak → lossRate → userId` — 기획 나열 순서가 곧 우선순위.
   패율 1차면 "1전 1패가 개돼지왕"이 되는 서사 역전. userId 는 결정성 타이브레이커(0전 다수 동률).
   **공동 순위 없음** — 포디움 방어를 앱에 시키지 않고 서버가 전순서로 원천 차단
2. **`lossRate`**: 서버 계산 정수 %(반올림), 0전=0(폴백이 아니라 사실 진술), **표시값=정렬값**.
   재계산 금지 — `totalChallenges` 가 있어도 분모로 쓰지 않는다 (grep 검증)
3. **"나" 식별 = `isMe`** — challenge-result 의 `amIChallenger` 기각과 같은 타입인데 판정이 갈린
   근거는 **실패 모드의 방향**: 키 누락 시 저건 승리→패배 반전(틀린 걸 보여줌), 이건 하이라이트
   미표시(없는 게 보임)
4. **0전 구분 = `totalChallenges: Int`** (`hasRecord` 기각 — Int 는 서버가 **사실**을, Boolean 은
   **규칙**을 소유하게 된다). 0전 캡션 "아직 기록 없음". 전승자 별도 표기 없음(무패를 자랑거리로
   세우면 화면 축이 뒤집힌다)
5. **`rankings` 는 절대 비지 않는다**(나 항상 포함) — 빈 상태 판정은 `size == 1`
6. **애니메이션 판정선**: transform·alpha 구현 / box-shadow glow 보류 — 앱의 기존 선례 3개로 그음.
   `wiggle` 은 로그인 값 승계, `pulse-fire` 는 정적 fire 브러시로 대체
7. 🔴 **아바타는 이니셜 유지 + 활성화 선행 조건 발견** — 실측으로 카카오 CDN URL 이 실재하나
   **`http://` 평문이라 iOS 만 ATS 차단**(Android 는 통과 — 한쪽만 깨지는 실패). 서버 https 정규화
   (유입 1곳, `fname` 이중 http 함정 포함)를 백로그 선행 조건으로 등재
8. 🔴 **팀 프로세스 교훈 3건** (전부 에이전트 자기 교정으로 도출, 각 문서에 박제):
   ① 기각 사유를 실제 이유보다 강하게 적지 마라 ② **실측 보고와 스코프 판단을 분리하라**
   (backend 가 실측에서 "두 갈래 구현하라"까지 밀었다 철회 — 자기 근거가 반대 결론을 지지하고 있었다)
   ③ **사실의 소유자는 한 곳** — 가까운 곳에 사본을 두지 말고 가리켜라. + 부칙: **작성 중 문서로
   계약을 닫지 않는다**(미완성 design.md 를 근거로 confirmed 직전까지 간 건 — 자진 철회로 차단)
