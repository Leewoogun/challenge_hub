## 2. 주요 기능

### 2.1 카카오 로그인
- 카카오 소셜 로그인으로 간편 가입
- 프로필 사진, 닉네임 자동 연동

> 📝 **변경 이력 (2026-04-23)**: 로그인 단계의 SMS 인증 제거 — 카카오 로그인만으로 식별. 전화번호는 친구 매칭용으로 다른 시점에 별도 등록 (플로우 결정: ADR-0008).

### 2.2 친구 관리
- **전화번호부 연동**: 내 연락처에서 앱 가입자를 자동 탐색
- **친구 검색**: 닉네임 또는 전화번호로 친구 검색
- **친구 요청/수락**: 친구 요청 → 상대방 수락 시 친구 목록에 추가
- **친구 목록**: 친구별 전적(승/패/무) 표시
- **친구 프로필**: 최근 챌린지 이력, 달성률 확인 가능

### 2.3 챌린지 신청
- 친구 목록에서 **대결 상대 선택**
- 각자 본인이 수행할 챌린지 내용을 자유롭게 입력
  - 예) 나: "오늘 운동 1시간", 친구: "오늘 책 30페이지 읽기"
- 챌린지 기간: **하루 단위** (당일 자정까지)
- 챌린지 신청 → 상대방 수락 시 챌린지 시작

### 2.4 영혼의 맹세 (계약서)
- 챌린지 시작 전 **반드시** 작성해야 하는 계약서
- 계약서 내용:
  - 챌린지 내용 (각자의 미션)
  - 내기 내용 (진 사람이 해야 할 것)
    - 예) "커피 사기", "밥 사기", "SNS에 망신 사진 올리기"
  - 챌린지 날짜 및 인증 마감 시간
- **AI STT 작성 기능**: 음성으로 계약서 내용을 말하면 자동 텍스트 변환
- **서명 기능**: 양측 모두 화면에 직접 서명해야 계약 성립
- 작성 완료된 계약서는 수정 불가 (증거 보존)

### 2.5 챌린지 인증
- **카메라 촬영 인증**: 실시간 카메라로 촬영한 사진만 허용 (갤러리 선택 불가)
- 인증 사진 업로드 시 타임스탬프 자동 기록
- 상대방에게 인증 사진 실시간 전달
- 인증 마감 시간 전까지 미인증 시 자동 패배

### 2.6 챌린지 결과 판정
- **양측 모두 인증 완료** → 무승부
- **한쪽만 인증** → 인증한 쪽 승리
- **양측 모두 미인증** → 양쪽 모두 패배
- 결과 확정 시 계약서와 함께 결과 카드 생성

## 3. 부가 기능

### 3.1 알림 (푸시 알림)
- 챌린지 신청 알림
- 영혼의 맹세 서명 요청 알림
- 인증 마감 1시간 전 리마인드 알림
- 상대방 인증 완료 알림 ("상대가 인증했어! 너도 서둘러!")
- 챌린지 결과 알림

### 3.2 전적 및 통계
- **1:1 전적 기록**: 친구별 승/패/무 전적
- **종합 통계**: 총 챌린지 수, 승률, 연승 기록
- **월별 달성 캘린더**: 날짜별 챌린지 성공/실패 시각화

### 3.3 계약서 보관함
- 과거 작성한 모든 영혼의 맹세 열람 가능
- 서명, 내기 내용, 결과까지 한눈에 확인
- "이때 너 이거 걸었잖아" — 증거 자료로 활용

### 3.4 명예의 전당
- 연승 기록 보유자 랭킹
- 이번 주/이번 달 가장 많이 챌린지한 유저
- 친구 간 랭킹 (내 친구 중 1위는 누구?)

### 3.5 도발 기능
- 챌린지 진행 중 상대방에게 **도발 메시지** 전송
  - 기본 제공 문구: "아직도 안 했어?", "포기는 배추 셀 때나", "각오해라 😏"
  - 사용자 직접 입력도 가능
- 도발 메시지 수신 시 푸시 알림

### 3.6 공유 기능
- 챌린지 결과 카드를 **카카오톡/인스타 스토리** 등 SNS 공유
- 계약서 이미지 공유 ("이 사람 약속 안 지켰습니다" 활용)

## 4. 화면 구성 (IA)

| 화면 | 설명 |
|---|---|
| 스플래시 | 앱 로고 + 슬로건 |
| 로그인 | 카카오 로그인 버튼 |
| 전화번호 등록 (친구 매칭용) | 카카오 SDK 동의 또는 설정에서 직접 입력 (SMS 인증 없음 — ADR-0008) |
| 홈 | 진행 중인 챌린지 목록, 새 챌린지 만들기 버튼 |
| 챌린지 상세 | 챌린지 내용, 계약서, 인증 상태, 결과 |
| 챌린지 신청 | 친구 선택 → 미션 입력 → 내기 입력 |
| 영혼의 맹세 작성 | 계약서 내용 입력 (STT) + 서명 |
| 인증 카메라 | 카메라 촬영 → 인증 제출 |
| 친구 목록 | 친구 리스트 + 전적 + 친구 추가 |
| 친구 프로필 | 상대 전적, 최근 챌린지, 대결 신청 |
| 마이페이지 | 내 프로필, 통계, 계약서 보관함, 설정 |
| 통계 | 월별 캘린더, 승률, 연승 기록 |
| 명예의 전당 | 랭킹 리스트 |
| 알림 | 알림 목록 (신청, 인증, 결과 등) |

## 5. 기술 스택 (예상)

| 구분 | 기술 |
|---|---|
| 플랫폼 | Android (Kotlin) |
| 아키텍처 | Clean Architecture + MVI |
| UI | Jetpack Compose |
| 로그인 | Kakao SDK |
| 음성 인식 (STT) | Google Speech-to-Text API 또는 Kakao Neuro STT |

| 이미지 저장 | Firebase Storage 또는 AWS S3 |
| 푸시 알림 | FCM (Firebase Cloud Messaging) |
| 서버 | Spring Boot + PostgreSQL (또는 Firebase) |
| 실시간 동기화 | WebSocket 또는 Firebase Realtime DB |

## 6. 향후 확장 가능 기능

- **그룹 챌린지**: 2명 이상이 참여하는 단체 챌린지
- **연속 챌린지**: 하루가 아닌 N일 연속 챌린지 모드
- **벌칙 자동 실행**: 패배 시 자동으로 송금 (토스페이 연동 등)
- **AI 챌린지 추천**: 사용자 패턴 분석 후 챌린지 미션 추천
- **챌린지 템플릿**: 자주 쓰는 챌린지를 저장해두고 재사용
